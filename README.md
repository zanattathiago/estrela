# Estrela Tarefas

Organizador pessoal: oito tarefas no topo que, quando concluídas, vão completando a estrela.

- Página única: `index.html` (HTML, CSS e JavaScript, sem dependências).
- Funciona como app: no iPhone, abra no Safari e use Compartilhar → Adicionar à Tela de Início.
- Sincronização: as tarefas ficam num Gist secreto da sua conta do GitHub. Toque no indicador de sincronização no topo e cole uma chave (token clássico com a permissão `gist`). Use a mesma chave em todos os aparelhos.
